# P-5.2.0 — Investigation Workspace prerequisites (contract freeze)

**Status:** ✅ Complete, awaiting review · **Date:** 2026-08-03 · **Type:** contract + specification
freeze. **No implementation.**

The gate between P-5.1 and P-5.2. Eleven recommendations arrived with the P-5.1 approval, all of the
form _define the contract before implementation_; three refinement sets arrived during the work.
This milestone discharges the freeze half and stops.

⚠️ **Nothing here is wired.** Nine new contract modules, and no service reads or writes any of them.
That is the intended state: the workspace slice consumes settled shapes rather than inventing them
mid-build.

## The finding

⚠️ **`audit:read` would have granted a staff-surveillance log to every viewer in every tenant.**

`operator` and `viewer` both hold `*:read`. Naming the access-audit permission the obvious way would
have granted _who viewed what, when, from which IP_ to the least privileged role — **at the moment
the string was written**, with no grant recorded, nothing failing, and no test asserting the
negative.

Measured, not suspected: `can(ROLE_PERMISSIONS.viewer, 'audit:read')` returns `true`, and that
assertion is now in the suite so the hazard is pinned rather than merely avoided. The permission is
`audit:inspect`.

The general defect is worse than this instance — **every** future `<resource>:read` is granted to
viewers the moment it is named. Recorded as **TD-26**; narrowing the wildcard is breaking and needs
its own ADR.

## What was refused, and why

| Refused                                                                        | Reason                                                                                             |
| ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| `audit` events for assignment · comment · attachment · resolution · escalation | Already appended to the incident's streams and derived by `IncidentActivity`. A second copy is §46 |
| `audit:view`                                                                   | At list-row granularity, one write per rendered row. `open` records the act anyone asks about      |
| `audit` for evidence byte access                                               | Owned by the hash-chained `EvidenceCustodyAction.accessed` — the artefact a court sees             |
| Search entities `site` · `building` · `floor` · `zone`                         | The `type` of a `location`. Four entities would copy the frozen hierarchy enum into search         |
| Search entity `actor`                                                          | Not an entity — a reference. It has no record to return                                            |
| Search entity `operator` (supported)                                           | Identity has no indexed principal search, and directory disclosure needs its own permission        |
| `search:query` permission                                                      | Search is federated over per-entity gates; a second gate can disagree with the first               |
| `report:generate` permission                                                   | `incident:export` already authorises it                                                            |
| `audit:write` / `audit:delete`                                                 | The log is append-only. The absence is the guarantee                                               |
| A global relevance score                                                       | Incomparable quantities across federated contexts (§52)                                            |
| A `partial` job state                                                          | "Partly succeeded" is where the incomplete archive gets handed to a regulator                      |
| A signed URL inside `JobResult`                                                | It outlives its expiry: a broken link at best, a credential in a queryable collection at worst     |
| A cached title in persisted tab state                                          | It survives revoked access and renders stale confidently                                           |
| A second design-system document                                                | Two descriptions of one visual language, with no way to decide which the code is wrong against     |
